# 20 Arayüz (UI/UX) ekranları

| Ekran | İçerik |
|---|---|
| Ana görünüm (HUD) | 3D izometrik ofis. Üst bar: nakit, tarih, hız kontrolleri, itibar, AP. Sol: hızlı menü ikonları (Müşteriler, Kampanyalar, Ekip, Ofis, Finans, Ar-Ge, Bilgi Defteri). Sağ: bildirim akışı. Görsel referansındaki gibi yuvarlak köşeli, sıcak renkli ikon butonları. |
| Gelen kutusu | Brief'ler, teklifler, olaylar; döneme göre değişen arayüz kaplaması (faks/e-posta/Slak). |
| Müşteri portföyü | Kartlar: logo, sektör, memnuniyet barı, güven, sözleşme, yıllık gelir, risk etiketi. |
| Kampanya sihirbazı | Adım adım: Brief özeti → Hedef → Kitle → Ton → Kanal karışımı (sürükle-bırak bütçe çubuğu) → Ekip → Onay. Her adımda Bilgi Defteri ipuçları. |
| Faz slider ekranı | GDT'deki gibi 3 slider + fazın kalan süresi + canlı S/K/T sayaçları. |
| Kampanya raporu | Puan (büyük, animasyonlu), jüri/medya yorumları (GDT'nin 4 inceleme sitesi karşılığı: "Reklam Dünyası", "Pazarlama Gazetesi", "Kreatif Blog", "Müşteri"), KPI kartları, açıklama cümleleri. |
| Ekip | Çalışan listesi, stat radar grafiği, enerji/moral barları, eğitim butonu, maaş. |
| İnşa modu | Oda çizme, mobilya katalogu, oda kalitesi göstergesi. |
| Finans | Grafikler, müşteri kârlılığı, krediler. |
| Bilgi Defteri | Keşfedilen uyum tabloları (renkli ızgara), kanal geçmişi, önceki kampanyaların puanları. |
| Sektör ve ödül sıralaması | Rakip ajanslar listesi, yıllık sıralamalar. |

## UX ilkeleri

Her ekran en fazla 2 tıkla ulaşılır · Önemli sayıların yanında "neden?" tooltip'i · Klavye kısayolları (Boşluk = duraklat, 1/2/3 = hız) · Kontrollerin hepsi fare ile yapılabilir · Metin boyutu ayarı · Renk körlüğü dostu palet (+/− işaretleri renge ek olarak sembol de taşır, tablolarımızdaki gibi).
