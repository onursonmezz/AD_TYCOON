# 4 Çekirdek oyun döngüsü

## 4.1 Döngüler

| Döngü | Süre | İçerik |
|---|---|---|
| Mikro | Saniyeler | Çalışanlar çalışır, puan baloncukları (S/K/T) uçar, olay bildirimleri, kriz kararları. |
| Kampanya | 2–12 oyun haftası (1–6 dk) | Brief al → kampanyayı tasarla (kombinasyon + kanal karışımı + bütçe) → 3 fazı yürüt (slider) → teslim → yayın → rapor + müşteri tepkisi. |
| Ajans | Oyun yılı (~10–15 dk) | İşe alım, eğitim, ofis/oda yatırımı, yazılım abonelikleri, pitch'ler, festivaller, araştırma. |
| Dönem | 5–8 oyun yılı | Yeni mecralar ve araçlar, büyük kriz/olay, ofis seviyesi atlama, yeni geç-oyun hedefleri. |

## 4.2 Bir kampanyanın yaşam döngüsü

```text
[Brief gelir] ─► [Kabul / pazarlık / ret]
       │
       ▼
[Kampanya Kurulumu]  Sektör (brief'ten) + Hedef + Kitle + Kanal karışımı + Ton + Büyüklük
       │             Ekip ataması (Account, Strateji, Kreatif, Prodüksiyon, Medya)
       ▼
[Faz 1: STRATEJİ]    Pazar Araştırması / İçgörü (Insight) / Konumlandırma   ─ slider
[Faz 2: KREATİF]     Konsept / Metin (Copy) / Görsel Tasarım                ─ slider
[Faz 3: PRODÜKSİYON] Prodüksiyon / Medya Planlama / Ölçümleme               ─ slider
       │  (ara olaylar: müşteri revizyonu, kriz, matbaa gecikmesi…)
       ▼
[Müşteri onayı]    Memnun değilse revizyon turu (zaman + moral maliyeti)
       ▼
[Yayın]   Kanallarda 2–8 hafta yayında; haftalık KPI akışı
       ▼
[Rapor]   Kalite puanı (1–10), KPI'lar, müşteri memnuniyeti, ödül adaylığı, gelir
       ▼
[Sonuç]   İtibar, müşteri bütçesi artar/azalır, çalışan XP, bilgi defteri güncellenir
```

## 4.3 Oyuncu kararlarının özeti

- Hangi brief'i kabul edeyim? (Para vs itibar vs ekip kapasitesi vs portföy çeşitliliği)
- Hangi kombinasyon? (Uyum tabloları + trendler + tekrar cezası)
- Bütçeyi hangi kanallara nasıl bölerim? (Erişim, maliyet, sinerji)
- Kimi atayayım? (Yetenek, hız, enerji, maaş, kişilik uyumu)
- Hangi matbaa/tedarikçi? (Fiyat, kalite, süre, güvenilirlik)
- Para ile ne yapayım? (İşe alım, eğitim, ofis, yazılım, Ar-Ge, pitch, festival başvurusu)
